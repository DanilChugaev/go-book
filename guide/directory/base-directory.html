Базовые понятия

Данный раздел — это всесторонний справочник (глоссарий) по базовым понятиям и концепциям Go. Он организован по категориям для удобства, с алфавитным указателем в конце. Каждое понятие объяснено просто, с примерами кода (где применимо), аналогиями и ссылками на связанные концепции.

Цель

Чтобы при встрече нового термина в коде или документации ты мог быстро вернуться сюда и понять суть.

В основе спецификация Go (The Go Programming Language Specification) и актуальные версии (1.23+ на 2025 год).

Справочник не охватывает advanced темы (например, unsafe или generics в деталях), но фокусируется на базовых.

Для практики: Скопируй примеры в main.go и запусти go run main.go.

1. Основы языка и структура программы

Package (Пакет)

Группа файлов с кодом, объединённая по функциональности.

Каждый Go-файл начинается с package <name>. package main — для исполняемых программ (с функцией main()). Другие пакеты — для библиотек (импортируются).

Аналогия: Пакет — как модуль в Python или namespace в C++.

Пример:

package main  // Это основной пакет

Связанные: Import, Module.

Import (Импорт)

Подключение внешних пакетов (библиотек) для использования их функций/типов.

Используй import "package/name". Стандартные пакеты (fmt, os) в GOROOT; пользовательские — в GOPATH или modules.

Аналогия: Как import math в Python.

Пример:

import "fmt"  // Для Println
import (
    "os"
    "time"
)  // Многострочный импорт

Связанные: Package, Module.

Подводный камень: Unused imports — ошибка компиляции.

Main function (Функция main)

Точка входа в программу.

Должна быть в package main. Не принимает аргументов, ничего не возвращает.

Аналогия: Как main() в C или точка старта приложения.

Пример:

func main() {
    // Код начинается здесь
}

Связанные: Function, os.Args (для аргументов командной строки).

Module (Модуль)

Система управления зависимостями (с Go 1.11+).

Файл go.mod определяет версию Go и зависимости. Инициализируй go mod init <name>.

Аналогия: Как package.json в Node.js.

Пример

В терминале:

go mod init example.com/myapp
go get github.com/some/lib # добавляем зависимость

Связанные: Import, go.sum (checksums для безопасности).

Compilation (Компиляция)

Процесс преобразования кода в бинарный исполняемый файл.

Команды: go build (создаёт бинарник), go run (компилирует и запускает временно). Go — статически типизированный, так что ошибки типов ловятся на этапе компиляции.

Аналогия: Как javac в Java, но быстрее и с статической линковкой (все зависимости в одном файле).

Связанные: Build tags (для conditional compilation, как //go:build linux).

2. Переменные и типы данных

Variable (Переменная)

Именованное место в памяти для хранения данных.

Объявление: var name type = value (явное) или name := value (короткое, авто-тип). Переменные должны использоваться (unused — ошибка).

Аналогия: Коробка с ярлыком, где лежит значение.

Пример:

var age int = 25  // Явное
name := "Alice"   // Короткое (string)

Связанные: Type, Constant.

Type (Тип)

Определяет, какие данные может хранить переменная и операции над ними.

Базовые: int (целые, 32/64-bit), uint (беззнаковые), float32/float64 (дробные), bool (true/false), string (строки, immutable), byte (uint8, для байтов), rune (int32, для Unicode-символов).

Аналогия: Форма коробки — круглая для шаров, квадратная для кубов.

Пример: var pi float64 = 3.14.

Связанные: Composite types (array, slice, map, struct), Type conversion (e.g., int(float64Var)).

Constant (Константа)

Неизменяемое значение, объявляется const name = value.

Могут быть типизированными или untyped (авто).

Аналогия: Зафиксированное правило, как Pi в математике.

Пример:

const Pi = 3.14
const DaysInWeek int = 7

Связанные: Iota (для последовательных констант, как enum: const ( Mon iota; Tue )).

Zero value (Нулевое значение)

Значение по умолчанию для неинициализированных переменных.

Для int — 0, string — "", bool — false, pointer/slice/map/chan — nil.

Аналогия: Пустая коробка, когда ничего не положили.

Пример: var s string // s == "".

Связанные: Nil (специальное значение для "ничего").

3. Коллекции и составные типы

Array (Массив)

Фиксированная последовательность элементов одного типа.

Размер — часть типа: [3]int. Передаётся по значению (копируется).

Аналогия: Фиксированная полка с ячейками.

Пример:

var arr [2]string = [2]string{"Go", "Lang"}
fmt.Println(arr[0])  // Go

Связанные: Slice (динамическая версия).

Slice (Слайс)

Динамическая "ссылка" на часть массива.

Структура: указатель на данные + len (длина) + cap (ёмкость). Передаётся по ссылке.

Аналогия: Вид на полку, который можно расширять.

Пример:

s := []int{1, 2, 3}
s = append(s, 4)  // [1 2 3 4]
fmt.Println(len(s), cap(s))  // 4 4 (или больше)

Связанные: Make (make([]int, len, cap)), Range.

Map (Мапа)

Ассоциативный массив (ключ-значение), как hash-таблица.

Ключи уникальны, порядок не гарантирован.

Аналогия: Словарь, где по слову находишь определение.

Пример:

m := map[string]int{"age": 25}
m["height"] = 180
delete(m, "age")
val, ok := m["height"]  // 180, true

Связанные: Make (make(map[K]V)).

Struct (Структура)

Составной тип для группировки данных (как record или class без методов).

Поля: имя + тип.

Аналогия: Форма с полями, как анкета.

Пример:

type Person struct {
    Name string
    Age  int
}
p := Person{Name: "Bob", Age: 30}
fmt.Println(p.Name)  // Bob

Связанные: Embedding (встраивание структур), Method.

Pointer (Указатель)

Переменная, хранящая адрес другой переменной.

Синтаксис: *T (указатель на T), &var (адрес).

Аналогия: Указатель на дом, а не сам дом.

Пример:

var ptr *int
i := 42
ptr = &i
*ptr = 43  // i теперь 43

Связанные: Nil, Dereferencing (*ptr). (Подробно отложено, но базово: для изменений по ссылке).

4. Функции и методы

Function (Функция)

Блок кода для повторного использования.

func name(params) returns { ... }. Может возвращать несколько значений.

Аналогия: Рецепт: ингредиенты (params), результат (returns).

Пример:

func add(a, b int) (int, error) {
    return a + b, nil
}

Связанные: Defer, Variadic (...args).

Method (Метод)

Функция, прикреплённая к типу (обычно struct).

Receiver: (r ReceiverType) или (r *ReceiverType).

Аналогия: Действие объекта, как "car.move()".

Пример:

func (p *Person) Birthday() {
    p.Age++
}

Связанные: Pointer receiver (для изменений), Value receiver (для копий).

Defer

Откладывает вызов функции до конца enclosing функции (после return).

Полезно для cleanup (close files).

Аналогия: "Сделай это перед уходом".

Пример:

defer fmt.Println("Done")  // Выполнится последним

Связанные: Panic/recover (defer ловит panic).

Variadic function (Вариадическая функция)

Принимает переменное число аргументов (...T). Внутри — как slice.

Аналогия: Функция для "любого количества гостей".

Пример:

func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
sum(1, 2, 3)  // 6

5. Контроль потока

If/else

Условное выполнение.

Нет скобок для условия. Может инициализировать переменные.

Пример:

if x > 0 { /*...*/ } else { /*...*/ }

Связанные: Short if (if err := func(); err != nil { ... }).

For

Единственный цикл.

Варианты: for init; cond; post {}, for cond {}, for range, infinite for {}. Нет while.

Пример:

for i := 0; i < 5; i++ { ... }
for _, v := range slice { ... }

Связанные: Break, Continue, Range.

Switch

Многоуровневое условие.

Case на выражениях, fallthrough для продолжения.

Пример:

switch os := runtime.GOOS; os {
case "darwin":
    fmt.Println("macOS")
default:
    fmt.Println("Other")
}

Связанные: Type switch (switch v := i.(type) { ... }).

Range

Итератор для коллекций (slice, map, chan, string).

Возвращает index/key и value.

Пример:

for i, v := range arr { /*...*/ } // (i — индекс, v — значение)

Связанные: For, Slice.

6. Интерфейсы и типы

Interface (Интерфейс)

Контракт — набор методов.

Тип реализует интерфейс implicitly (duck typing).

Аналогия: Розетка: любой прибор с подходящей вилкой работает.

Пример:

type Shaper interface {
    Area() float64
}

Связанные: Empty interface (interface{} — any type), Type assertion (i.(Type)).

Embedding (Встраивание)

В struct/interface — поля/методы "промотируются" от встроенного типа.

Аналогия: Наследование без классов.

Пример:

// Employee имеет поля/методы Person
type Employee struct {
    Person
}

Связанные: Struct, Interface.

7. Обработка ошибок

Error (Ошибка)

Встроенный интерфейс type error interface { Error() string }.

Функции возвращают error как второе значение.

Аналогия: Флаг "что-то пошло не так".

Пример:

_, err := someFunc()
if err != nil {
    fmt.Println(err.Error())
}

Связанные: errors.New, fmt.Errorf, Panic.

Panic/Recover

Runtime-ошибка (как exception).

Defer с recover() ловит panic.

Аналогия: Аварийная остановка.

Пример:

defer func() {
    if r := recover(); r != nil {
        fmt.Println("Recovered:", r)
    }
}()
panic("Error!")

Связанные: Defer.

8. Concurrency (Параллелизм)

Goroutine

Лёгкий "поток" — go func() { ... }().

Тысячи могут goroutine работать параллельно.

Аналогия: Фоновая задача, как асинхронный вызов.

Пример:

go worker()  // Запуск в фоне

Связанные: Channel, sync.WaitGroup.

Channel (Канал)

Для общения между goroutines. ch := make(chan int).

Буферизованные/небуферизованные.

Аналогия: Труба для передачи данных.

Пример:

ch <- 42  // Отправка
val := <-ch  // Получение

Связанные: Select, Close.

Select

Мультиплексор для channels. Ждёт события от нескольких chan.

Пример:

select {
    case v := <-ch1: ...
    case <-ch2: ...
    default: ...
}

Связанные: Channel.

Mutex (Мьютекс)

Для синхронизации доступа (из sync). Lock/Unlock.

Аналогия: Замок на двери — только один в комнате.

Пример:

var mu sync.Mutex
mu.Lock()
// Критическая секция
mu.Unlock()

Связанные: sync.RWMutex (для чтения/записи), Atomic (для простых операций).

9. Другие концепции

Nil

Специальное значение "ничего" для pointer, slice, map, chan, func, interface.

Аналогия: Пустая ссылка.

Пример:

var p *int  // p == nil

Связанные: Pointer, Zero value.

Make

Создаёт и инициализирует slice/map/chan.

Пример:

s := make([]int, 5, 10)  // len=5, cap=10

Связанные: New (new(T) — аллоцирует и возвращает *T с zero value).

Type assertion (Утверждение типа)

Извлечение underlying типа из interface. v, ok := i.(Type)

Пример: Для any (interface{}).

Связанные: Interface, Type switch.

Build (Сборка)

Процесс создания бинарника. go build, go install.

Связанные: Cross-compilation (GOOS=windows go build).
