Задания: нумерация и название задачи

Пока Task Manager API не хранит список задач, но мы уже можем смоделировать нумерацию и обработать отдельное название задачи.

Задание 1. Номера задач

Выведите номера задач от 1 до 5 в формате:

Задача №1
Задача №2
...
Задача №5

Используйте классическую форму for.

Критерии проверки:

  • счётчик начинается с 1;
  • последняя выведенная задача имеет номер 5;
  • цикл содержит начальное значение, условие и изменение счётчика;
  • номера выводятся по порядку.
Подсказка

Начало цикла:

for taskNumber := 1; taskNumber <= 5; taskNumber++ {
	// вывод
}
Решение
package main

import "fmt"

func main() {
	for taskNumber := 1; taskNumber <= 5; taskNumber++ {
		fmt.Printf("Задача №%d\n", taskNumber)
	}
}

Задание 2. Пропустите служебную задачу

Выведите номера задач от 1 до 5, но пропустите задачу №3. Используйте continue.

Критерии проверки:

  • в цикле есть continue;
  • задача №3 не выводится;
  • задачи №1, 2, 4 и 5 выводятся;
  • цикл не завершается раньше времени.
Подсказка

Перед выводом проверьте if taskNumber == 3, а внутри ветви используйте continue.

Решение
package main

import "fmt"

func main() {
	for taskNumber := 1; taskNumber <= 5; taskNumber++ {
		if taskNumber == 3 {
			continue
		}

		fmt.Printf("Задача №%d\n", taskNumber)
	}
}

Задание 3. Остановите обработку

Программа обрабатывает задачи с номерами от 1 до 10, но должна остановиться перед задачей №6. Используйте break.

Критерии проверки:

  • в цикле есть break;
  • выводятся номера с 1 по 5;
  • номера 6 и больше не выводятся;
  • break находится до команды вывода.
Подсказка

Сравните номер с 6. Если числа равны, завершите цикл до fmt.Println.

Решение
package main

import "fmt"

func main() {
	for taskNumber := 1; taskNumber <= 10; taskNumber++ {
		if taskNumber == 6 {
			break
		}

		fmt.Printf("Обработана задача №%d\n", taskNumber)
	}
}

Задание 4. Символы названия

Для названия задачи Купить молоко выведите каждую руну с новой строки. Не выводите байтовый индекс.

Критерии проверки:

  • используется for range;
  • индекс заменён на _;
  • каждая буква, пробел и другие символы выводятся отдельной строкой;
  • кириллические буквы отображаются корректно.
Подсказка

Используйте форму for _, symbol := range title. Для вывода руны как символа подойдёт fmt.Println(string(symbol)).

Решение
package main

import "fmt"

func main() {
	title := "Купить молоко"

	for _, symbol := range title {
		fmt.Println(string(symbol))
	}
}

Проверьте себя

Перед следующей главой убедитесь, что вы можете:

  • написать цикл с условием и классический for;
  • объяснить разницу между break и continue;
  • избежать ошибки на единицу в условии цикла;
  • объяснить, почему индекс range для строки — это индекс байта;
  • использовать _, когда часть результата цикла не нужна.
