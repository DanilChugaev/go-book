Массивы и слайсы

Цель урока

Научиться хранить несколько значений одного типа, различать массив и слайс, добавлять и удалять элементы, а также безопасно работать с индексами.

В Task Manager API первым набором данных станет список названий задач. Пока это []string; позже мы заменим строки полноценными структурами задач.

Зачем нужны коллекции

До сих пор одна переменная хранила одно значение:

title := "Купить молоко"

Но приложению обычно нужно работать с несколькими задачами. Можно объявить много переменных, но это неудобно:

firstTitle := "Купить молоко"
secondTitle := "Оплатить интернет"
thirdTitle := "Прочитать книгу"

Для набора однотипных значений используют массивы и слайсы.

Массив

Массив хранит фиксированное число элементов одного типа. Размер указан в типе:

var priorities [3]int

В этом массиве ровно три целых числа. Его начальные значения — нулевые:

fmt.Println(priorities) // [0 0 0]

Массив можно заполнить сразу:

priorities := [3]int{1, 2, 3}
titles := [2]string{"Купить молоко", "Оплатить интернет"}

Размер входит в тип массива. [2]string и [3]string — разные типы, даже если оба содержат строки.

var shortList [2]string
var fullList [3]string

// shortList = fullList // ошибка: разные типы

Массивы полезны, когда размер действительно фиксирован. В прикладном Go чаще нужны слайсы, потому что количество задач обычно меняется.

Индексы

Элементы массива и слайса нумеруются с нуля:

titles := [3]string{"Купить молоко", "Оплатить интернет", "Прочитать книгу"}

fmt.Println(titles[0]) // Купить молоко
fmt.Println(titles[2]) // Прочитать книгу

Доступ к индексу за границей вызывает panic во время работы программы:

// fmt.Println(titles[3]) // panic: index out of range

Длина коллекции получается функцией len:

fmt.Println(len(titles)) // 3

Последний допустимый индекс — len(titles) - 1. Перед доступом по индексу из переменной всегда проверяйте границы:

index := 1

if index >= 0 && index < len(titles) {
	fmt.Println(titles[index])
}

Слайс

Слайс — последовательность значений, длину которой можно менять. Его тип записывают без размера в квадратных скобках:

var titles []string

Нулевое значение слайса — nil. Читать его длину и обходить в цикле безопасно:

var titles []string

fmt.Println(titles == nil) // true
fmt.Println(len(titles))   // 0

Создать непустой слайс можно литералом:

titles := []string{
	"Купить молоко",
	"Оплатить интернет",
	"Прочитать книгу",
}

В отличие от массива, количество элементов не является частью типа:

shortList := []string{"Первая задача"}
fullList := []string{"Первая задача", "Вторая задача"}

shortList = fullList // допустимо: оба значения имеют тип []string

append: добавить элемент

append добавляет один или несколько элементов в слайс и возвращает обновлённый слайс.

titles := []string{"Купить молоко"}

titles = append(titles, "Оплатить интернет")
titles = append(titles, "Прочитать книгу", "Позвонить врачу")

fmt.Println(titles)

Важно присваивать результат обратно. append может создать новый внутренний массив, поэтому старый заголовок слайса не всегда меняется сам:

titles := []string{"Купить молоко"}

// append(titles, "Оплатить интернет") // результат потерян
titles = append(titles, "Оплатить интернет")

append работает и с nil-слайсом:

var titles []string
titles = append(titles, "Купить молоко")

fmt.Println(titles) // [Купить молоко]

len и cap

len — количество доступных элементов. cap — вместимость слайса до выделения нового внутреннего массива.

titles := make([]string, 2, 5)

fmt.Println(len(titles)) // 2
fmt.Println(cap(titles)) // 5

В начале в слайсе уже есть два элемента с нулевым значением "". Третий аргумент make необязателен:

titles := make([]string, 0, 5)

fmt.Println(len(titles)) // 0
fmt.Println(cap(titles)) // 5

Такой вариант полезен, если вы заранее знаете примерное число элементов и собираетесь добавлять их через append.

На первых этапах не пытайтесь вручную управлять вместимостью без необходимости. Обычно достаточно литерала и append.

Срез слайса

Из части слайса можно получить другой слайс выражением from:to. Начальная граница включается, конечная — нет:

titles := []string{
	"Купить молоко",
	"Оплатить интернет",
	"Прочитать книгу",
}

importantTitles := titles[0:2]
fmt.Println(importantTitles) // [Купить молоко Оплатить интернет]

Сокращённые формы:

firstTwo := titles[:2] // от начала до индекса 2, не включая его
afterFirst := titles[1:] // от индекса 1 до конца
allTitles := titles[:] // все элементы

Границы должны находиться в диапазоне от 0 до len(titles). В противном случае будет panic.

Удаление элемента по индексу

В Go нет встроенной команды «удалить элемент слайса». Обычно объединяют часть до элемента и часть после него:

titles := []string{
	"Купить молоко",
	"Оплатить интернет",
	"Прочитать книгу",
}

index := 1
titles = append(titles[:index], titles[index+1:]...)

fmt.Println(titles) // [Купить молоко Прочитать книгу]

Перед этим обязательно проверяйте индекс:

if index >= 0 && index < len(titles) {
	titles = append(titles[:index], titles[index+1:]...)
}

Три точки ... передают элементы второго слайса в append по отдельности.

copy: независимая копия

Простое присваивание не создаёт независимую копию элементов:

titles := []string{"Купить молоко", "Оплатить интернет"}
backup := titles

backup[0] = "Изменённая задача"
fmt.Println(titles[0]) // Изменённая задача

Если нужна отдельная копия, создайте слайс нужной длины и используйте copy:

titles := []string{"Купить молоко", "Оплатить интернет"}
backup := make([]string, len(titles))

copy(backup, titles)
backup[0] = "Изменённая задача"

fmt.Println(titles[0]) // Купить молоко
fmt.Println(backup[0]) // Изменённая задача

copy возвращает число скопированных элементов. Оно равно меньшей из длин исходного и целевого слайсов.

Обход слайса через range

Слайс удобно обходить циклом range:

titles := []string{"Купить молоко", "Оплатить интернет"}

for index, title := range titles {
	fmt.Printf("%d. %s\n", index+1, title)
}

Здесь index начинается с нуля, поэтому для пользовательской нумерации добавлено 1.

Если индекс не нужен, используйте _:

for _, title := range titles {
	fmt.Println(title)
}

Частые ошибки

Использование append без присваивания

titles := []string{"Купить молоко"}
append(titles, "Оплатить интернет")

fmt.Println(titles) // [Купить молоко]

Сохраните возвращаемое значение: titles = append(titles, "Оплатить интернет").

Индекс вне границ

titles := []string{"Купить молоко"}
// fmt.Println(titles[1]) // panic

У одного элемента допустим только индекс 0.

make с ненулевой длиной вместо пустого списка

titles := make([]string, 3)
titles = append(titles, "Купить молоко")

fmt.Println(titles) // [   Купить молоко]

Если нужны три места для будущих добавлений, используйте make([]string, 0, 3), а не make([]string, 3).

Изменение копии range-значения

В for _, title := range titles переменная title — копия текущего значения. Изменение её не изменит элемент слайса. Для изменения элемента нужен индекс; эту тему подробнее разберём на практических задачах после структур.
