Операторы и выражения

Цель урока

Научиться выполнять вычисления, сравнивать значения, объединять условия в логические выражения и понимать, в каком порядке Go вычисляет части выражения.

Операторы понадобятся уже в Task Manager API: например, чтобы узнать длину заголовка, сравнить приоритет с допустимым диапазоном или проверить несколько требований к задаче одновременно.

Что такое выражение

Выражение — это фрагмент кода, который вычисляет значение.

priority + 1    // вычисляет число
priority >= 1   // вычисляет true или false
!completed      // вычисляет противоположное логическое значение

Оператор — это символ или ключевое слово, которое участвует в таком вычислении: +, >=, &&, ! и другие.

Арифметические операторы

Для целых и дробных чисел доступны основные операции:

ОператорЗначениеПример
+сложение2 + 3 → 5
-вычитание5 - 2 → 3
*умножение4 * 3 → 12
/деление7 / 2 → 3 для int
%остаток от деления7 % 2 → 1
package main

import "fmt"

func main() {
	totalTasks := 7
	completedTasks := 3
	remainingTasks := totalTasks - completedTasks

	fmt.Println(remainingTasks) // 4
	fmt.Println(totalTasks % 2) // 1
}

Деление целых чисел

Если оба операнда имеют целочисленный тип, дробная часть результата отбрасывается:

totalTasks := 7
days := 2

fmt.Println(totalTasks / days) // 3

Если нужен дробный результат, преобразуйте хотя бы один операнд в float64:

averagePerDay := float64(totalTasks) / float64(days)
fmt.Println(averagePerDay) // 3.5

Остаток от деления

Оператор % полезен, когда нужно узнать, делится ли число без остатка:

taskCount := 8
isEven := taskCount%2 == 0

fmt.Println(isEven) // true

Операторы сравнения

Операторы сравнения всегда возвращают bool: true или false.

ОператорЗначение
==равно
!=не равно
<меньше
<=меньше или равно
>больше
>=больше или равно
package main

import "fmt"

func main() {
	priority := 2

	fmt.Println(priority == 2) // true
	fmt.Println(priority != 1) // true
	fmt.Println(priority >= 1) // true
	fmt.Println(priority > 3)  // false
}

Строки тоже можно сравнивать на равенство:

status := "new"
isNew := status == "new"

fmt.Println(isNew) // true

= и == — разные операторы

= присваивает значение переменной, а == сравнивает два значения.

priority = 2      // присваивание
isDefault := priority == 2 // сравнение

Логические операторы

Логические операторы работают со значениями типа bool.

ОператорЗначениеРезультат
&&Иtrue, если оба выражения истинны
``
!НЕменяет true на false и наоборот

Для Task Manager API можно составить проверку допустимого приоритета без ветвления:

package main

import "fmt"

func main() {
	priority := 2
	isValidPriority := priority >= 1 && priority <= 3

	fmt.Println(isValidPriority) // true
}

Проверка названия задачи может состоять из нескольких требований:

titleLength := len("Купить молоко")
hasValidLength := titleLength > 0 && titleLength <= 120

fmt.Println(hasValidLength) // true

&& и || используют короткое замыкание: Go вычисляет левую часть первой и не вычисляет правую, если итог уже известен. Например, в false && expression правая часть не будет вычислена.

Присваивание и изменение значения

Обычное присваивание:

priority = 3

Сокращённые формы объединяют операцию и присваивание:

taskCount := 5

taskCount += 2 // 7
taskCount -= 1 // 6
taskCount *= 2 // 12
taskCount /= 3 // 4

Для увеличения или уменьшения целого числа на единицу есть ++ и --:

taskCount := 5
taskCount++ // 6
taskCount-- // 5

В Go ++ и -- — отдельные инструкции, а не выражения. Их нельзя использовать внутри другого выражения:

// nextCount := taskCount++ // ошибка
taskCount++
nextCount := taskCount

Приоритет операций

Как в математике, умножение и деление выполняются раньше сложения и вычитания:

result := 2 + 3*4
fmt.Println(result) // 14

Круглые скобки делают порядок явным:

result := (2 + 3) * 4
fmt.Println(result) // 20

При сложных выражениях ставьте скобки, даже если помните приоритет. Так код проще проверять и поддерживать.

Полезное упрощённое правило:

  1. сначала выполняются *, /, %;
  2. затем + и -;
  3. затем сравнения: <, <=, >, >=, ==, !=;
  4. затем &&;
  5. затем ||.

Переполнение чисел

Тип числа имеет ограниченный диапазон. При переполнении значения переменной результат может «перейти через границу» диапазона:

package main

import "fmt"

func main() {
	var priority int8 = 127
	priority++

	fmt.Println(priority) // -128
}

С переполнением не нужно экспериментировать в бизнес-логике. Для обычных счётчиков выбирайте int; при данных из внешнего источника проверяйте диапазон до преобразования к более узкому типу.

Частые ошибки

Ожидание дробного результата от int / int

fmt.Println(7 / 2) // 3, не 3.5

Используйте float64, если нужна дробная часть.

Использование одного = в сравнении

// isHigh := priority = 3 // ошибка
isHigh := priority == 3

Неверный порядок вычислений

limit := 2 + 3*4   // 14
expected := (2 + 3) * 4 // 20

Когда смысл зависит от порядка, ставьте скобки.
