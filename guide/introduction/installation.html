Установка и настройка

Цель урока

Установить актуальную версию Go, проверить её в терминале и подготовить редактор для работы с кодом.

Установите Go

Откройте официальную страницу Download and install Go и выберите свою операционную систему. Следуйте инструкции именно оттуда: она поддерживается авторами Go и не привязана к устаревшему номеру версии.

Коротко по платформам:

  • Windows: скачайте и запустите официальный MSI-инсталлятор.
  • macOS: скачайте официальный пакет для Intel или Apple Silicon и пройдите шаги установщика.
  • Linux: скачайте архив с официальной страницы, распакуйте его по инструкции и добавьте Go в PATH.

Не настраивайте лишнего

Не нужно вручную задавать GOROOT или создавать GOPATH, чтобы начать писать современные Go-проекты. Установщик на Windows и macOS обычно настраивает путь к команде go; проекты можно хранить в любой удобной директории.

Если команда go не найдена после установки, закройте и снова откройте терминал. На Linux проверьте шаг с добавлением /usr/local/go/bin в PATH в официальной инструкции.

Проверьте установку

Откройте терминал — PowerShell или Windows Terminal в Windows, Terminal в macOS либо привычный эмулятор терминала в Linux — и выполните:

go version

Команда должна вывести установленную версию Go и вашу платформу, например:

go version go1.x.x darwin/arm64

Число версии и платформа будут отличаться — это нормально.

Для инструментов, которые позднее будут установлены через go install, полезно добавить каталог $(go env GOPATH)/bin в PATH. На данном этапе это не обязательно.

Выберите редактор

Подойдёт любой текстовый редактор, но для начала рекомендуются:

  • Visual Studio Code с официальным расширением Go;
  • GoLand — коммерческая IDE;
  • редактор, которым вы уже уверенно пользуетесь, если он поддерживает Go и gopls.

После установки расширения Go VS Code может предложить установить дополнительные инструменты. Соглашайтесь на рекомендуемые: среди них будет gopls, который показывает ошибки, подсказывает код и запускает форматирование.

Чек-лист

Перед следующим уроком убедитесь, что:

  • команда go version выполняется без ошибки;
  • вы можете открыть терминал в папке проекта;
  • выбран редактор и установлена поддержка Go.

Если что-то не получилось

  • go: command not found или «команда не найдена» — перезапустите терминал и проверьте PATH по официальной инструкции.
  • Команда показывает неожиданно старую версию — возможно, в системе осталась старая установка. Воспользуйтесь разделом Managing Go installations.
  • Не удаётся установить расширение редактора — это не мешает продолжить: Go можно писать в обычном текстовом редакторе и запускать из терминала.
