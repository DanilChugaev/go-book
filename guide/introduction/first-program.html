Первая программа и Go-модуль

Цель урока

Создать первый Go-проект, понять назначение go.mod, запустить программу через go run . и разобрать её основные части.

Создайте папку проекта

В терминале перейдите в место, где хотите хранить учебные проекты. Например, создайте каталог go-learning в домашней директории:

mkdir -p ~/go-learning
cd ~/go-learning
mkdir hello-go
cd hello-go

В Windows можно создать и открыть папку через проводник, а затем выбрать в ней Open in Terminal. Главное — выполнять дальнейшие команды внутри папки hello-go.

Создайте модуль

Выполните:

go mod init example.com/hello-go

Go создаст файл go.mod. В нём хранится имя вашего модуля, версия Go и позднее появятся зависимости проекта.

Что такое модуль

Модуль — это единица проекта и управления зависимостями в Go. Для учебного проекта имя example.com/hello-go подходит: такой адрес не обязан существовать в интернете. Когда код попадёт в GitHub, имя обычно станет похожим на github.com/ваше-имя/hello-go.

Проверьте содержимое папки:

hello-go/
└── go.mod

Напишите программу

Создайте в этой папке файл main.go и вставьте код:

package main

import "fmt"

func main() {
	fmt.Println("Привет, Go!")
}
Открыть Go Playground

Скопируйте пример, вставьте его в Go Playground и нажмите Run.

Запустите проект

В той же папке выполните:

go run .

Точка означает «текущая папка». Команда найдёт пакет main в текущем модуле, временно скомпилирует его и запустит. Вы увидите:

Привет, Go!

Почему go run ., а не go run main.go

Обе команды возможны для простого одного файла. Но go run . запускает пакет целиком и остаётся корректным, когда в нём появится несколько .go-файлов. Поэтому далее в учебнике будем использовать этот вариант.

Разберём программу

package main

Каждый Go-файл начинается с объявления пакета. Файлы одной папки с одинаковым именем пакета компилируются вместе.

main — специальное имя пакета для исполняемой программы. Чтобы Go мог запустить пакет main, в нём должна быть функция main.

import "fmt"

import подключает пакет с готовым кодом. fmt — часть стандартной библиотеки Go; в нём есть функции для форматированного ввода и вывода.

Компилятор не разрешит оставить импорт, который не используется. Это помогает поддерживать код чистым.

func main()

func объявляет функцию. main — точка входа: именно с неё начинается работа исполняемой программы.

func main() {
	// инструкции программы
}

Функция main не принимает аргументы и не возвращает результат. Ошибки в Go обычно обрабатывают внутри программы или возвращают из других функций как значение error — это разберём позднее.

fmt.Println

fmt.Println выводит переданные значения в стандартный вывод — обычно это окно терминала — и добавляет перевод строки в конце.

Попробуйте изменить программу:

func main() {
	fmt.Println("Привет, Go!")
	fmt.Println("Я создал первый модуль.")
}

Форматирование кода

Go придерживается единого формата кода. Примените его к текущей папке:

gofmt -w main.go

Редактор с поддержкой Go обычно запускает форматирование при сохранении. Не выравнивайте код вручную пробелами: это делает gofmt.

Сборка исполняемого файла

Чтобы собрать программу без запуска, используйте:

go build .

В папке появится исполняемый файл с именем проекта: hello-go в macOS/Linux или hello-go.exe в Windows. Его можно запустить из терминала:

./hello-go

В PowerShell для Windows:

.\hello-go.exe

Важно

Исполняемый файл создаётся для текущей ОС и архитектуры. В следующих главах он нам не нужен, поэтому после эксперимента его можно удалить вручную.

Частые ошибки

go: cannot find main module

Вы запустили go run . до команды go mod init или находитесь не в папке проекта. Перейдите в hello-go и создайте модуль.

undefined: fmt

Используется fmt.Println, но отсутствует import "fmt".

imported and not used

Пакет импортирован, но ни одна его функция или тип не используется. Удалите импорт либо добавьте использование.

package ... is not a main package

Для запуска программы нужны package main и функция func main().

Чек-лист

Вы готовы двигаться дальше, если можете:

  • создать папку для проекта;
  • выполнить go mod init;
  • создать main.go;
  • запустить проект командой go run .;
  • объяснить назначение package main, import и func main().
