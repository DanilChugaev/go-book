Переменные

Эта глава — одна из самых важных, потому что без понимания переменных и типов ты просто не сможешь писать корректный код на Go.

Инфо

Go — статически типизированный язык с явной типизацией (в большинстве случаев), и компилятор проверяет всё на этапе сборки.

Здесь мы разберём всё максимально подробно: от объявления переменных до нюансов работы со строками и рунами, с примерами, аналогиями и типичными ошибками новичков.

Что такое переменная и зачем она нужна?

Переменная — это именованное место в памяти компьютера, где хранится какое-то значение.

Аналогия: Представь, что у тебя есть коробка с наклейкой (имя переменной). В коробку ты можешь положить число, текст или что-то ещё. Пока коробка существует — значение доступно по имени.

В Go переменные должны:

  1. Быть объявлены (или созданы через :=).
  2. Быть использованы (иначе — ошибка компиляции: declared but not used).
  3. Иметь тип (явно или неявно).

Способы объявления переменных

В Go есть три основных способа объявить переменную:

СпособСинтаксисГде использоватьПример
Полное объявлениеvar имя тип = значениеГлобальные переменные, когда нужен явный типvar age int = 25
Короткое объявлениеимя := значениеТолько внутри функцийname := "Alice"
Без значенияvar имя типКогда нужно нулевое значениеvar count int → count == 0

Примеры в коде:

package main

import "fmt"

func main() {
    // 1. Полное объявление
    var age int = 30
    var name string = "Bob"

    // 2. Короткое объявление (самый популярный способ внутри функций)
    height := 180          // int
    isActive := false     // bool
    pi := 3.14             // float64

    // 3. Объявление без инициализации (получает zero value)
    var score int          // score == 0
    var message string     // message == ""

    fmt.Println(age, name, height, isActive, pi, score, message)
}

Важно

:= можно использовать только внутри функций. В глобальной области — только var.

Zero Values (Нулевые значения)

Если переменная объявлена, но не инициализирована — она автоматически получает нулевое значение своего типа. Это фундаментальная фича Go — нет неинициализированных "мусорных" переменных, как в C.

ТипНулевое значение (zero value)
int, float64 и др. числовые0
boolfalse
string"" (пустая строка)
pointer, slice, map, chan, func, interfacenil
structвсе поля — свои zero values

Пример:

var (
    i int
    f float64
    b bool
    s string
    p *int
    m map[string]int
)

fmt.Printf("%v %v %v %q %v %v\n", i, f, b, s, p, m)
// Вывод: 0 0 false "" <nil> map[]

6. Константы

Константы объявляются через const и вычисляются на этапе компиляции.

const Pi = 3.14159
const (
    Monday = 1
    Tuesday = 2
    // ...
)

// iota — автоинкремент
const (
    Red = iota    // 0
    Green         // 1
    Blue          // 2
)

Константы могут быть untyped (без типа) — это удобно, пока не присвоишь переменной.

Основные правила именования

Имена переменных в Go (идентификаторы) должны быть осмысленными, чтобы код был читаемым. Go чувствителен к регистру: age и Age — разные переменные. Но есть строгие правила, чтобы избежать конфликтов с языком.

  • Допустимые символы: Начинается с буквы (a-z, A-Z) или подчёркивания (_), за которым могут следовать буквы, цифры или подчёркивания. Нет пробелов, специальных символов (@, $, etc.).
  • Стиль: Go использует camelCase для переменных (firstName), PascalCase для экспортируемых (FirstName — visible outside package). Подчёркивания (_) для игнорирования значений (blank identifier).
  • Длина: Нет лимита, но будь краток: userAge лучше, чем theAgeOfTheCurrentUserInYears.
  • Экспорт: Если имя начинается с большой буквы — оно экспортируется (visible в других пакетах). С маленькой — private к пакету.
  • Аналогия: Имя переменной — как адрес дома: должен быть уникальным в районе (scope), читаемым и не конфликтовать с "запрещёнными зонами" (ключевыми словами).

Пример хороших имён:

var userName string   // camelCase, private
var MaxUsers int = 100 // PascalCase, exported
var _ignored = 42     // _ для игнорирования (не вызывает unused error)

Пример плохих имён (ошибка компиляции):

var 1age int         // Начинается с цифры
var user-name string // Тире не разрешено
var user name string // Пробел

Ключевые слова, которые нельзя использовать в названиях переменных

Go имеет 25 reserved keywords (зарезервированные слова), которые используются языком для синтаксиса. Их нельзя применять как имена переменных, функций, типов или пакетов — компилятор выдаст ошибку: invalid identifier. Это предотвращает путаницу.

Полный список ключевых слов:

  • break — прерывает цикл/switch.
  • case — ветвь в switch.
  • chan — тип для channels.
  • const — объявление констант.
  • continue — продолжает цикл.
  • default — дефолтная ветвь в switch/select.
  • defer — откладывает выполнение.
  • else — альтернатива в if.
  • fallthrough — продолжает case в switch.
  • for — цикл.
  • func — объявление функций.
  • go — запуск goroutine.
  • goto — прыжок (редко используется, не рекомендуется).
  • if — условие.
  • import — импорт пакетов.
  • interface — объявление интерфейсов.
  • map — тип для мап.
  • package — объявление пакета.
  • range — итерация в for.
  • return — возврат из функции.
  • select — мультиплексор для channels.
  • struct — объявление структур.
  • switch — множественное условие.
  • type — объявление типов.
  • var — объявление переменных.

Пример ошибки:

var if int = 5    // Ошибка: expected identifier, found 'if' (reserved word)
var func string = "test"  // Аналогично

Советы:

  • Если хочешь использовать похожее имя — добавь префикс/суффикс: myIf вместо if.
  • Ключевые слова — это "защищённые" термины языка, как команды в терминале — нельзя переопределять.
  • Проверяй имена: Go компилятор подскажет, если имя reserved.
  • Для глобальных: Избегай конфликтов с импортированными именами (например, не называй переменную fmt).

Объявление нескольких переменных одного типа через запятую

Go позволяет объявлять несколько переменных одного типа в одной строке, разделяя их запятыми. Это упрощает код, когда переменные логически связаны (например, координаты x, y, z). Можно инициализировать все или часть.

Синтаксис:

  • var имя1, имя2, имя3 тип = значение1, значение2, значение3 (полное).
  • var имя1, имя2, имя3 тип (без значений — zero values).
  • имя1, имя2 := значение1, значение2 (короткое, только в функциях).

Примеры в коде:

package main

import "fmt"

func main() {
    // 1. Полное объявление нескольких одного типа
    var x, y, z int = 1, 2, 3
    fmt.Println(x, y, z)  // 1 2 3

    // 2. Без инициализации (zero values)
    var a, b, c float64
    fmt.Println(a, b, c)  // 0 0 0

    // 3. Короткое объявление
    width, height := 800, 600
    fmt.Println(width, height)  // 800 600

    // 4. Смешанная инициализация (некоторые с значениями, другие zero)
    var p, q, r int = 10, 20, 0  // r явно 0, но могло быть и без
    fmt.Println(p, q, r)  // 10 20 0

    // 5. В глобальной области (только var)
}

var global1, global2 string = "Hello", "World"  // Глобальные

Шаг за шагом, что происходит:

  1. Компилятор видит var x, y, z int — аллоцирует память для трёх int (по 4/8 байт каждая).
  2. Если инициализация — присваивает значения слева направо.
  3. Если типов несколько — нельзя в одной строке: var a int, b string — ошибка. Нужно отдельные строки или блок var ( ... ).
  4. В коротком := — типы определяются автоматически, но они должны быть совместимы (нельзя a, b := 1, "str" в одной, если не в multi-return функции).

Блок var для нескольких:

Для разных типов или читаемости используй блок:

var (
    count int = 0
    name  string = "Alice"
    active bool
)

Аналогия: Объявление через запятую — как список покупок: "купить яблоки, бананы, апельсины (все фрукты)" — короче, чем отдельно.

Типичные ошибки:

  • Несовпадение количества: var a, b int = 1 — ошибка (нужно 2 значения или none).
  • Смешивание типов: var a, b int, string — ошибка.
  • Использование := глобально: Ошибка (только в функциях).

Дополнительные советы по переменным

  • Scope (Область видимости): Переменные в функциях — локальные, глобальные — visible в пакете. Блок {} ограничивает scope (например, в if).
  • Shadowing: Внутренняя переменная может "затенять" внешнюю с тем же именем — будь осторожен.
  • Unused: Go заставляет использовать все — это предотвращает мёртвый код.
  • Производительность: Простые типы (int) — на стеке, сложные (string) — могут быть на heap (GC управляет).

12. Практические задания для закрепления (дополнение)

  1. Напиши код с объявлением нескольких переменных одного типа (через запятую), включая глобальные и локальные.
  2. Попробуй использовать reserved keyword как имя переменной — посмотри ошибку компилятора.
  3. Создай переменные с именами в разных регистрах и проверь экспорт (в другом файле пакета).
