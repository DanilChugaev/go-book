Базовые типы, строки и преобразования

Цель урока

Научиться выбирать базовые типы для данных, понимать разницу между байтами и символами в строке и явно преобразовывать совместимые значения.

Целые числа

Для обычных целых чисел чаще всего используется int:

taskCount := 3
priority := 2

Размер int зависит от архитектуры компьютера: обычно это 64 бита на современных машинах, но полагаться на конкретный размер не стоит. Когда размер важен — например, формат данных или внешний API требует 64-битное число — используйте явный тип int64.

ТипКогда нужен
intОбычные целые числа: счётчики, индексы, приоритеты
int8, int16, int32, int64Когда важны диапазон или размер числа
uint8, uint16, uint32, uint64Беззнаковые значения, если они действительно нужны
byteПсевдоним uint8, обычно для сырых байтов
runeПсевдоним int32, обычно для Unicode-кода символа

Не выбирайте uint только потому, что число не бывает отрицательным. В прикладном коде смешивание знаковых и беззнаковых чисел нередко усложняет вычисления. Начинайте с int, пока нет конкретной причины выбрать другой тип.

Дробные числа

Для дробных значений обычно используют float64:

progress := 0.75

float64 хранит приближённые значения. Поэтому для денег его обычно не используют: 0.1 + 0.2 в двоичной системе может быть представлено неточно. Для денежных сумм в реальном приложении выбирают подходящее целочисленное представление или специальную библиотеку; к этой задаче вернёмся в проектной части.

Логический тип bool

bool принимает только два значения: true и false.

completed := false
hasDescription := true

В Go нельзя использовать число вместо логического значения:

// if 1 { } // ошибка

Условия и операторы сравнения мы подробно разберём в следующей главе.

Строки

string — неизменяемая последовательность байтов. Строковые литералы обычно записывают в двойных кавычках:

title := "Купить продукты"
message := "Задача создана"

Строки можно соединять оператором +:

title := "Купить " + "продукты"

Для удобного вывода нескольких значений лучше использовать fmt.Println или fmt.Printf, а не собирать длинные строки вручную.

Байты, руны и Unicode

Go хранит текст в UTF-8. len для строки возвращает количество байтов, а не число символов, которые видит человек.

package main

import "fmt"

func main() {
	title := "Go!"
	russianTitle := "Го"

	fmt.Println(len(title))        // 3 байта
	fmt.Println(len(russianTitle)) // 4 байта
}

Чтобы посчитать количество Unicode-символов (рун), используйте пакет unicode/utf8:

package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	title := "Задача"

	fmt.Println(len(title))                  // 12 байтов
	fmt.Println(utf8.RuneCountInString(title)) // 6 рун
}

rune — это значение Unicode-кода. Если нужно обратиться к строке как к последовательности рун, можно преобразовать её в []rune. Сам слайс мы изучим позднее; здесь достаточно запомнить, что такое преобразование нужно для безопасной работы с отдельными символами Unicode.

title := "Го"
runes := []rune(title)
fmt.Printf("%c\n", runes[0]) // Г

Строка неизменяема

Нельзя изменить один байт или символ по индексу: title[0] = 'Г' не скомпилируется. Чтобы получить новую строку, создайте новое значение.

Явные преобразования типов

Go не выполняет неявные преобразования между числовыми типами. Тип нужно указывать явно:

priority := 2
priorityAsFloat := float64(priority)

fmt.Println(priorityAsFloat) // 2

Общий вид:

newValue := Type(value)

При преобразовании float64 в int дробная часть отбрасывается, а не округляется:

progress := 3.9
completedSteps := int(progress)

fmt.Println(completedSteps) // 3

Преобразование может привести к потере данных. Например, большое число не поместится в маленький тип:

value := 300
smallValue := uint8(value)

fmt.Println(smallValue) // 44

Перед преобразованием убедитесь, что значение находится в допустимом диапазоне.

Частые ошибки

Ожидание числа символов от len

fmt.Println(len("Привет")) // 12, а не 6

Если нужна длина текста в рунах, используйте utf8.RuneCountInString.

Неявное преобразование

var priority int = 2
// var score float64 = priority // ошибка
score := float64(priority)

Преобразование не равно валидации

int(value) не проверяет, что value подходит для бизнес-правил. Например, int(-0.7) вернёт 0. Проверку допустимых значений мы добавим, когда разберём условия.
