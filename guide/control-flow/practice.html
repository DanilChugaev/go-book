Задания: валидация задачи

Продолжим Task Manager API. Теперь программа не только вычислит проверки, но и сообщит пользователю первую найденную проблему.

Задание 1. Проверка заголовка

Создайте программу с переменной title. Она должна выводить:

  • Название задачи не должно быть пустым, если заголовок пустой;
  • Название задачи слишком длинное, если длина заголовка больше 120 байтов;
  • Название задачи корректно во всех остальных случаях.

Сначала проверьте программу с title := "Купить молоко", а затем с title := "".

Критерии проверки:

  • используется if / else if / else;
  • проверка пустой строки находится раньше проверки максимальной длины;
  • для корректного заголовка выводится сообщение об успехе;
  • для пустого заголовка выводится сообщение об ошибке.
Подсказка

Пустая строка: len(title) == 0. Слишком длинная строка: len(title) > 120.

Решение
package main

import "fmt"

func main() {
	title := "Купить молоко"

	if len(title) == 0 {
		fmt.Println("Название задачи не должно быть пустым")
	} else if len(title) > 120 {
		fmt.Println("Название задачи слишком длинное")
	} else {
		fmt.Println("Название задачи корректно")
	}
}

Задание 2. Проверка приоритета

Добавьте переменную priority. Она может принимать значения от 1 до 3. Выведите сообщение Приоритет должен быть от 1 до 3, если значение находится вне диапазона. В остальных случаях выведите Приоритет корректен.

Проверьте программу для значений 2, 0 и 4.

Критерии проверки:

  • проверка использует priority < 1 || priority > 3;
  • значение 2 считается корректным;
  • значения 0 и 4 считаются некорректными.
Подсказка

Некорректный приоритет — это значение меньше 1 или больше 3.

Решение
package main

import "fmt"

func main() {
	priority := 2

	if priority < 1 || priority > 3 {
		fmt.Println("Приоритет должен быть от 1 до 3")
	} else {
		fmt.Println("Приоритет корректен")
	}
}

Задание 3. Полная валидация

Объедините проверки из предыдущих заданий. Программа должна вывести только первую ошибку в таком порядке:

  1. пустой заголовок;
  2. слишком длинный заголовок;
  3. некорректный приоритет;
  4. Задачу можно создать, если ошибок нет.

Критерии проверки:

  • используется одна цепочка if / else if / else;
  • за один запуск выводится только одно сообщение;
  • с title := "" и priority := 5 первой выводится ошибка заголовка;
  • с корректным заголовком и priority := 2 выводится сообщение об успехе.
Подсказка

Расположите проверки в той же последовательности, что и в условии задания. else должен содержать сообщение об успехе.

Решение
package main

import "fmt"

func main() {
	title := "Купить молоко"
	priority := 2

	if len(title) == 0 {
		fmt.Println("Название задачи не должно быть пустым")
	} else if len(title) > 120 {
		fmt.Println("Название задачи слишком длинное")
	} else if priority < 1 || priority > 3 {
		fmt.Println("Приоритет должен быть от 1 до 3")
	} else {
		fmt.Println("Задачу можно создать")
	}
}

Задание 4. Текстовое описание приоритета

Используйте switch, чтобы вывести текстовое описание значения priority:

  • 1 — Низкий приоритет;
  • 2 — Средний приоритет;
  • 3 — Высокий приоритет;
  • любое другое значение — Неизвестный приоритет.

Критерии проверки:

  • используется switch priority;
  • есть три case и default;
  • после case нет лишних break;
  • для priority := 2 выводится Средний приоритет.
Подсказка
switch priority {
case 1:
	// ...
default:
	// ...
}
Решение
package main

import "fmt"

func main() {
	priority := 2

	switch priority {
	case 1:
		fmt.Println("Низкий приоритет")
	case 2:
		fmt.Println("Средний приоритет")
	case 3:
		fmt.Println("Высокий приоритет")
	default:
		fmt.Println("Неизвестный приоритет")
	}
}

Проверьте себя

Перед следующей главой убедитесь, что вы можете:

  • написать if / else if / else без круглых скобок вокруг условия;
  • выбрать правильный порядок проверок;
  • использовать || для проверки выхода за диапазон;
  • объяснить область видимости переменной из короткого объявления в if;
  • выбрать между if и switch.
