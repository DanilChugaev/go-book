# Рекомендации по коду: условия

- Проверяйте ошибочные и граничные случаи раньше успешного пути: это уменьшает вложенность.
- Используйте ранний `return`, если после ошибки дальнейшая работа не имеет смысла.
- Выбирайте `if` для диапазонов и составных условий, а `switch` — для одного значения с несколькими конкретными вариантами.
- Не сравнивайте `bool` с `true` или `false`, если достаточно `if completed` или `if !completed`.
- Не добавляйте `break` в обычный `switch`: Go завершает подходящий `case` сам.
- Короткое объявление в `if` используйте только для значения, нужного именно этому условию.

## Чек-лист

Валидация сообщает первую понятную проблему, ветви расположены от специальных условий к общим, а `else` не содержит большой основной сценарий после ошибки.
