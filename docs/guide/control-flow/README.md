# Условия: `if` и `switch`

## Цель урока

Научиться выполнять код по условию, проверять несколько вариантов и выводить понятное сообщение при валидации будущей задачи.

В предыдущей главе мы вычисляли `true` и `false`. Теперь используем эти значения, чтобы программа могла выбрать нужное действие.

## `if`

Конструкция `if` выполняет блок кода, только если условие имеет значение `true`.

```go
package main

import "fmt"

func main() {
	priority := 3

	if priority == 3 {
		fmt.Println("Высокий приоритет")
	}
}
```

В Go условие записывается без круглых скобок, а фигурные скобки обязательны:

```go
if priority > 0 {
	fmt.Println("Приоритет задан")
}
```

## `if` и `else`

`else` задаёт альтернативный блок, когда условие ложно:

```go
package main

import "fmt"

func main() {
	completed := false

	if completed {
		fmt.Println("Задача выполнена")
	} else {
		fmt.Println("Задача ещё в работе")
	}
}
```

Условие типа `bool` не нужно сравнивать с `true`:

```go
if completed { // предпочтительно
	fmt.Println("Готово")
}

// if completed == true { ... } // работает, но избыточно
```

## Несколько ветвей: `else if`

Когда вариантов больше двух, используйте `else if`:

```go
package main

import "fmt"

func main() {
	priority := 2

	if priority == 1 {
		fmt.Println("Низкий приоритет")
	} else if priority == 2 {
		fmt.Println("Средний приоритет")
	} else if priority == 3 {
		fmt.Println("Высокий приоритет")
	} else {
		fmt.Println("Неизвестный приоритет")
	}
}
```

Выполняется только первая ветвь с истинным условием. Поэтому проверки обычно располагают от более специальной к более общей.

## Валидация будущей задачи

Теперь можно превратить логические проверки в понятный результат для пользователя.

```go
package main

import "fmt"

func main() {
	title := "Купить молоко"
	priority := 2

	if len(title) == 0 {
		fmt.Println("Название задачи не должно быть пустым")
	} else if len(title) > 120 {
		fmt.Println("Название задачи длиннее 120 байтов")
	} else if priority < 1 || priority > 3 {
		fmt.Println("Приоритет должен быть от 1 до 3")
	} else {
		fmt.Println("Задачу можно создать")
	}
}
```

Такая последовательность проверок — основа валидации. Сначала программа находит первую проблему, а если проблем нет — сообщает об успехе. Когда мы изучим функции, вынесем эту логику из `main`.

## Короткое объявление внутри `if`

В `if` можно объявить переменную, доступную только в самом условии и его ветвях:

```go
if titleLength := len(title); titleLength > 120 {
	fmt.Println("Название слишком длинное:", titleLength)
}
```

Здесь сначала выполняется `titleLength := len(title)`, затем проверяется `titleLength > 120`.

Переменная не существует за пределами конструкции `if`:

```go
if titleLength := len(title); titleLength > 0 {
	fmt.Println("Название есть")
}

// fmt.Println(titleLength) // ошибка: переменная вне области видимости
```

Эта форма особенно полезна, когда промежуточное значение нужно только для одной проверки.

## `switch`

`switch` удобно использовать, когда одно значение сравнивается с несколькими вариантами. Например, для преобразования числового приоритета в текст:

```go
package main

import "fmt"

func main() {
	priority := 2

	switch priority {
	case 1:
		fmt.Println("Низкий приоритет")
	case 2:
		fmt.Println("Средний приоритет")
	case 3:
		fmt.Println("Высокий приоритет")
	default:
		fmt.Println("Неизвестный приоритет")
	}
}
```

В Go выполнение не «проваливается» в следующий `case` автоматически: после подходящей ветви `switch` завершается. Поэтому писать `break` после каждого `case` не нужно.

Несколько совпадающих значений можно перечислить через запятую:

```go
switch priority {
case 1, 2:
	fmt.Println("Обычный приоритет")
case 3:
	fmt.Println("Срочная задача")
default:
	fmt.Println("Некорректный приоритет")
}
```

## Когда выбрать `if`, а когда `switch`

Используйте `if`, когда:

- проверяете диапазон: `priority >= 1 && priority <= 3`;
- объединяете условия через `&&` и `||`;
- проверяете разнородные условия;
- важен порядок проверки ошибок.

Используйте `switch`, когда:

- сравниваете одно значение с несколькими конкретными вариантами;
- каждой ветви соответствует своё понятное действие;
- цепочка `else if` стала длинной и хуже читается.

## Частые ошибки

### Присваивание вместо сравнения

```go
// if priority = 3 { } // ошибка
if priority == 3 {
	fmt.Println("Высокий приоритет")
}
```

### Неверный порядок проверок

```go
title := ""

if len(title) <= 120 {
	fmt.Println("Длина подходит") // сработает и для пустой строки
} else if len(title) == 0 {
	fmt.Println("Пустое название")
}
```

Проверку пустой строки нужно поставить первой либо объединить условия:

```go
if len(title) == 0 {
	fmt.Println("Пустое название")
} else if len(title) <= 120 {
	fmt.Println("Длина подходит")
}
```

### Лишний `break` в `switch`

```go
switch priority {
case 1:
	fmt.Println("Низкий")
	// break не нужен
}
```
