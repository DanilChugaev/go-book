# Строки и обработка текста

## Цель урока

Понять устройство строк в Go, разницу между байтами и рунами, а также научиться очищать, искать, разделять и собирать текст через пакет `strings`.

Названия задач — пользовательский текст. Чтобы корректно считать символы, убирать лишние пробелы и готовить данные к валидации, нужно знать особенности строк и UTF-8.

## Строка в Go

`string` — неизменяемая последовательность байтов. Строковые литералы обычно записывают в двойных кавычках:

```go
title := "Купить продукты"
message := "Задача создана"
```

Строки можно соединять оператором `+`:

```go
title := "Купить " + "продукты"
```

Исходную строку изменить нельзя:

```go
title := "Го"
// title[0] = 'П' // ошибка компиляции
```

Функции пакета `strings` и операции конкатенации создают новое строковое значение.

## Байты, руны и UTF-8

Go хранит текст в UTF-8. `len` для строки возвращает количество **байтов**, а не символов, которые видит человек:

```go
package main

import "fmt"

func main() {
	title := "Go!"
	russianTitle := "Го"

	fmt.Println(len(title))        // 3 байта
	fmt.Println(len(russianTitle)) // 4 байта
}
```

`byte` — псевдоним `uint8`; он подходит для отдельных байтов. `rune` — псевдоним `int32`, обычно представляющий Unicode-код символа.

Чтобы посчитать количество рун, используйте `unicode/utf8`:

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	title := "Задача"

	fmt.Println(len(title))                  // 12 байтов
	fmt.Println(utf8.RuneCountInString(title)) // 6 рун
}
```

Индексы строки относятся к байтам. Обход строки по Unicode-символам через `range` разберём в главе о циклах, после знакомства с `for`.

## Очистка текста: `strings.TrimSpace`

Пользователь может добавить пробелы в начале или конце названия:

```go
title := "  Купить молоко  "
cleanTitle := strings.TrimSpace(title)

fmt.Printf("%q\n", cleanTitle) // "Купить молоко"
```

`TrimSpace` удаляет пробелы, табуляции и переводы строк только с краёв. Внутренние пробелы сохраняются:

```go
title := "Купить   молоко"
fmt.Println(strings.TrimSpace(title)) // Купить   молоко
```

Текст нормализуют до валидации. Тогда строка из одних пробелов станет пустой и не пройдёт проверку.

## Поиск и изменение регистра

```go
title := "Купить МОЛОКО"

fmt.Println(strings.ToLower(title)) // купить молоко
fmt.Println(strings.ToUpper(title)) // КУПИТЬ МОЛОКО
```

`strings.Contains` проверяет наличие подстроки:

```go
title := "Купить молоко"
hasMilk := strings.Contains(strings.ToLower(title), "молоко")

fmt.Println(hasMilk) // true
```

Для поиска без учёта регистра приведите обе строки к одному регистру.

| Функция | Назначение |
| --- | --- |
| `strings.TrimSpace(s)` | Удаляет пробелы по краям |
| `strings.ToLower(s)` | Переводит в нижний регистр |
| `strings.ToUpper(s)` | Переводит в верхний регистр |
| `strings.Contains(s, sub)` | Проверяет наличие подстроки |
| `strings.HasPrefix(s, prefix)` | Проверяет начало строки |
| `strings.HasSuffix(s, suffix)` | Проверяет конец строки |

## Частые ошибки

### Ожидание числа символов от `len`

```go
fmt.Println(len("Привет")) // 12, а не 6
```

Если нужна длина текста в рунах, используйте `utf8.RuneCountInString`.

### Валидация до TrimSpace

```go
if len(title) == 0 {
	return ErrEmptyTitle
}

title = strings.TrimSpace(title)
```

Строка из пробелов пройдёт первую проверку. Сначала нормализуйте текст, затем валидируйте.
