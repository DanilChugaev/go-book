# Циклы: `for` и `range`

## Цель урока

Научиться повторять действия с помощью `for`, управлять выполнением через `break` и `continue`, а также обходить строку по Unicode-символам через `range`.

В Go есть только один ключевой цикл — `for`. Его формы покрывают обычные счётчики, циклы с условием и бесконечное повторение.

## Цикл с условием

Самая простая форма повторяет код, пока условие истинно:

```go
package main

import "fmt"

func main() {
	taskNumber := 1

	for taskNumber <= 3 {
		fmt.Printf("Задача №%d\n", taskNumber)
		taskNumber++
	}
}
```

В этом примере:

1. `taskNumber` получает значение `1`;
2. проверяется условие `taskNumber <= 3`;
3. выполняется тело цикла;
4. `taskNumber++` увеличивает счётчик;
5. проверка повторяется.

Если забыть изменить значение, от которого зависит условие, цикл может стать бесконечным.

## Классический `for`

Когда у цикла есть счётчик, обычно используют компактную форму из трёх частей:

```go
for начальное_значение; условие; изменение {
	// повторяемый код
}
```

Например, выведем номера первых пяти задач:

```go
package main

import "fmt"

func main() {
	for taskNumber := 1; taskNumber <= 5; taskNumber++ {
		fmt.Printf("Задача №%d\n", taskNumber)
	}
}
```

Область видимости `taskNumber` ограничена циклом: после него переменная недоступна.

Цикл можно вести в обратную сторону:

```go
for remaining := 3; remaining > 0; remaining-- {
	fmt.Println("Осталось задач:", remaining)
}
```

## Бесконечный цикл

`for` без условия выполняется бесконечно:

```go
for {
	// код будет повторяться всегда
}
```

Эта форма нужна, например, для постоянно работающего сервера или чтения событий. В учебных примерах она должна иметь понятный способ остановки, обычно через `break`.

```go
attempt := 1

for {
	fmt.Println("Попытка", attempt)

	if attempt == 3 {
		break
	}

	attempt++
}
```

## `break`: остановить цикл

`break` немедленно завершает ближайший цикл:

```go
package main

import "fmt"

func main() {
	for taskNumber := 1; taskNumber <= 10; taskNumber++ {
		if taskNumber == 4 {
			break
		}

		fmt.Printf("Задача №%d\n", taskNumber)
	}
}
```

Программа выведет только задачи с первой по третью. Когда счётчик станет равен `4`, код после `break` в теле цикла не выполнится.

## `continue`: пропустить текущий шаг

`continue` прекращает текущую итерацию и сразу переходит к следующей:

```go
package main

import "fmt"

func main() {
	for taskNumber := 1; taskNumber <= 5; taskNumber++ {
		if taskNumber == 3 {
			continue
		}

		fmt.Printf("Обработать задачу №%d\n", taskNumber)
	}
}
```

Третья задача не будет выведена, но цикл продолжится с четвёртой.

`continue` полезен, когда известно, что текущий элемент нужно пропустить. Не используйте его, если условие можно проще выразить через обычный `if`: читаемость важнее сокращения нескольких строк.

## `range` для строк

`range` позволяет обходить строку по рунам — Unicode-символам. Это важно для русскоязычных названий задач.

```go
package main

import "fmt"

func main() {
	title := "Go!"

	for byteIndex, symbol := range title {
		fmt.Printf("Байт %d: %c\n", byteIndex, symbol)
	}
}
```

У `range` для строки:

- первое значение — индекс **в байтах**;
- второе значение — текущая руна.

На кириллице это особенно заметно:

```go
package main

import "fmt"

func main() {
	title := "Го"

	for byteIndex, symbol := range title {
		fmt.Printf("Байт %d: %c\n", byteIndex, symbol)
	}
}
```

Вывод:

```text
Байт 0: Г
Байт 2: о
```

Если индекс не нужен, замените его на `_`:

```go
for _, symbol := range title {
	fmt.Println(string(symbol))
}
```

`_` называют пустым идентификатором: он явно показывает, что значение намеренно не используется.

::: info Почему пока только строки
`range` также работает со слайсами и map, но эти типы появятся в следующих главах. Сначала закрепим сам принцип цикла на строках и счётчиках.
:::

## Частые ошибки

### Бесконечный цикл из-за неизменяемого счётчика

```go
taskNumber := 1

for taskNumber <= 3 {
	fmt.Println(taskNumber)
	// taskNumber++ забыли
}
```

Условие всегда остаётся истинным. Добавьте изменение счётчика или используйте классическую форму `for`.

### Ошибка на единицу

```go
for taskNumber := 1; taskNumber < 3; taskNumber++ {
	fmt.Println(taskNumber)
}
```

Этот код выведет только `1` и `2`. Если нужно включить третью задачу, условие должно быть `taskNumber <= 3`.

### Ожидание индекса руны от `range`

```go
for index, symbol := range "Го" {
	fmt.Println(index, string(symbol))
}
```

`index` будет равен `0`, затем `2`, потому что это индекс байта в UTF-8, а не порядковый номер символа.
