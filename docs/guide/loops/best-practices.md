# Лучшие практики: циклы

- Предпочитайте простую форму `for range`, если не нужен ручной счётчик или особый шаг.
- Чётко определяйте границу цикла: `<=` включает последнее значение, `<` — нет.
- Используйте `break` для прекращения поиска, а `continue` — только когда это делает код понятнее обычного `if`.
- Не пишите бесконечный `for` без очевидного условия выхода, контекста отмены или читаемого `break`.
- При запуске goroutine в цикле передавайте значение параметром функции, чтобы намерение было явным.
- Помните, что индекс `range` для строки измеряется в байтах UTF-8.

## Чек-лист

Каждый цикл имеет понятное условие завершения, а тесты или примеры покрывают пустой набор, один элемент и границу диапазона.
