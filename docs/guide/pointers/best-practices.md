# Лучшие практики: указатели

- Используйте указатель, когда нужно изменить исходное значение, выразить отсутствие значения или избежать копирования действительно большой структуры.
- Всегда рассматривайте `nil` как возможное состояние указателя, если он приходит извне или хранится в поле.
- Выбирайте pointer receiver для методов, которые меняют структуру.
- Не используйте `*int`, `*string` или указатель на слайс/map без ясной причины — это усложняет API.
- Не разыменовывайте указатель до проверки `nil`, если nil допустим по контракту.
- Учитывайте, что значение структуры в map не адресуемо: получите копию, измените и присвойте обратно.

## Чек-лист

У каждого указателя есть понятная причина, методы изменения используют `*T`, а сценарии с `nil` не приводят к panic.
