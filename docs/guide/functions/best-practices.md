# Рекомендации по коду: функции

- Пусть функция выполняет одну понятную задачу и имеет имя-глагол: `validateTitle`, `loadTasks`, `saveTasks`.
- Передавайте данные параметрами, а не через глобальные переменные.
- Возвращайте значение вместо `fmt.Println`, если логика должна быть переиспользуема или тестируема.
- Проверяйте ошибку сразу после вызова и используйте ранний `return`.
- Не используйте именованные результаты только ради сокращения кода; они полезны, когда действительно делают сигнатуру понятнее.
- Если функция возвращает несколько значений, используйте `_` только для результата, который осознанно не нужен.

## Чек-лист

`main` управляет сценарием, а проверка, форматирование и преобразование данных вынесены в небольшие функции с понятными контрактами.
