# Лучшие практики: select и таймауты

- Создавайте общий таймер до цикла, если дедлайн относится ко всей операции, а не к каждой итерации.
- Используйте `default` только для осознанной неблокирующей проверки; не создавайте активный бесконечный цикл.
- Проверяйте второй результат получения из канала, если канал может закрыться.
- Отключайте закрытый канал через присваивание `nil`, если продолжаете ждать другие каналы в `select`.
- Помните: `time.After` прекращает ожидание, но не отменяет работу goroutine.
- Для настоящей отмены передавайте `context` в выполняемую операцию.

## Чек-лист

У таймаута есть ясная область действия, закрытые каналы обработаны, а завершение ожидания не оставляет заблокированных отправителей.
