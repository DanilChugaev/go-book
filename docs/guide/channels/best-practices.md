# Рекомендации по коду: каналы

- Используйте канал для передачи значений или сигналов между goroutine, а не как универсальный инструмент синхронизации.
- Выбирайте размер буфера по конкретной модели нагрузки, а не для случайного устранения deadlock.
- Закрывает канал только сторона, которая знает, что новых отправок больше не будет.
- Не отправляйте в закрытый канал и не закрывайте его дважды.
- Для `range` по каналу всегда должен быть понятный момент его закрытия.
- Используйте направленные каналы в сигнатурах, если функция только читает или только пишет.

## Чек-лист

У канала понятны владелец, отправители, получатели, правило закрытия и поведение, если получатель больше не ждёт результат.
