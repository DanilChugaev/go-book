# Рекомендации по коду: goroutine

- Запускайте goroutine только для независимой работы с ясным способом завершения.
- Не позволяйте `main` завершиться раньше нужных goroutine: используйте `WaitGroup`, канал или context.
- Вызывайте `wg.Add` до запуска goroutine, а `defer wg.Done()` ставьте в начале её тела.
- Не передавайте `WaitGroup` по значению после начала работы.
- Не используйте `time.Sleep` как синхронизацию.
- Не полагайтесь на порядок выполнения или вывода goroutine.

## Чек-лист

Для каждой goroutine понятно, кто её ждёт, как она завершится и что произойдёт при ошибке или отмене.
