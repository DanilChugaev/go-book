# Предисловие

::: info Дисклеймер
Основная часть глав учебника сгенерирована с помощью ИИ. Редактура и вычитка проводилась людьми.
:::

Этот учебник я решил создать для структурирования своих знаний, в процессе изучения языка. Он не претендует на полноту, а лишь отражает ту информацию, которую я изучил.

Я постарался сделать этот учебник в том виде, в котором сам хотел бы изучать язык GO.

Каждая глава включает:

- **Теорию**: подробное объяснение темы с примерами кода и комментариями
- **Тесты**: вопросы по теоретической части с выбором ответа
- **Задание**: короткие практические упражнения для закрепления полученных знаний
- **Дополнительные ресурсы**: список источников с дополнительной информацией по теме

::: tip Рекомендация
Для закрепления пройденного материала обязательно запускай пример кода. Причем лучше всего будет вводить код вручную. На практике информация запоминается легче.
:::
