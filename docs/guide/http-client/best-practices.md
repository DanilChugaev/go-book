# Рекомендации по коду: HTTP-клиент

- Создавайте и переиспользуйте `http.Client` как зависимость; задавайте его общий `Timeout`.
- Стройте request через `http.NewRequestWithContext` и передавайте context исходной операции дальше.
- Сразу после успешного `Do` вызывайте `defer response.Body.Close()`.
- Проверяйте HTTP-статус до декодирования успешного JSON; не-2xx — это не обязательно ошибка транспорта.
- Собирайте URL и query-параметры через `net/url`, а не конкатенацией пользовательских строк.
- Ограничивайте размер внешнего response body и проверяйте полученные данные, даже при `2xx`.
- Отделяйте внешний DTO от внутренних моделей и зависите от небольшого интерфейса клиента в service.
- Не логируйте токены, cookies, авторизационные заголовки и полные body.
- Не включайте retry без явной политики идемпотентности, backoff, лимитов и учёта context.
- Тестируйте HTTP-клиент через `httptest.Server`; unit-тесты не должны зависеть от публичных API или `time.Sleep`.

## Чек-лист

Внешний вызов ограничен по времени, отменяется вместе с родительской операцией, закрывает body, проверяет статус и JSON-контракт, а его поведение при успехе, ошибке статуса, плохом JSON и отмене закреплено детерминированными тестами.
