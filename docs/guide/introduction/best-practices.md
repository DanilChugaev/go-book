# Рекомендации по коду: старт с Go

- Устанавливайте Go только из [официального источника](https://go.dev/doc/install) и регулярно обновляйте версию.
- Создавайте `go.mod` в начале каждого нового проекта, даже если он состоит из одного файла.
- Запускайте проект командой `go run .`, а не отдельный файл: так команда останется корректной после добавления новых файлов.
- Форматируйте код через `gofmt` или настройте форматирование при сохранении в редакторе.
- Читайте сообщение компилятора до поиска ответа в интернете: Go обычно точно указывает файл, строку и причину ошибки.
- Не храните учебные и рабочие проекты в `GOPATH/src`: современный модульный Go этого не требует.

## Быстрый чек-лист

Перед следующим уроком убедитесь, что `go version`, `go run .`, `gofmt -w main.go` и `go build .` выполняются в папке проекта без ошибок.
