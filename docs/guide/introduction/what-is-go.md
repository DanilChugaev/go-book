# Что такое Go и зачем он нужен?

## Определение

> Go — это компилируемый статически типизированный язык программирования, созданный для решения проблем больших систем. Он сочетает простоту Python, скорость C и встроенную поддержку параллелизма (concurrency). Go идеален для backend, CLI-тулов, микросервисов и облачных приложений.

## История

Go разработан в Google в 2007 году Робом Пайком, Кеном Томпсоном (создатель Unix) и Робертом Гриземером. Первый релиз — 2009 год. Цели: упростить код, ускорить компиляцию, улучшить concurrency (goroutines вместо потоков). К 2025 году Go используется в Docker, Kubernetes, Uber, Netflix — это один из топ-языков по TIOBE index.

## Преимущества

- **Простота**: Минимум синтаксиса, нет классов/наследования (композиция вместо этого).
- **Скорость**: Компилируется в нативный бинарник, garbage collector (GC) эффективный.
- **Concurrency**: Встроенные goroutines и channels для параллельного кода без головной боли.
- **Безопасность**: Нет null-pointer exceptions (nil есть, но с проверками), встроенная обработка ошибок.
- **Кросс-платформенность**: Один бинарник работает на Windows, Linux, macOS.

## Минусы

- Строгая типизация (нужно привыкнуть после динамических языков).
- Нет generics до Go 1.18 (но теперь есть).
- Меньше библиотек, чем в Python.

## Когда использовать?

Для серверов, сетевых приложений, инструментов. Не для игр (лучше C++) или ML (лучше Python).
