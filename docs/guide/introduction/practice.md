# Практика: первый модуль

Выполняйте задания по порядку. Сначала попробуйте самостоятельно, затем откройте подсказку. Решение смотрите только после собственной попытки.

## Задание 1. Приветствие

Создайте модуль `example.com/hello-go`, добавьте файл `main.go` и выведите две строки:

```text
Привет, Go!
Я учусь писать backend на Go.
```

**Критерии проверки:**

- в папке проекта есть `go.mod` и `main.go`;
- команда `go run .` завершается без ошибок;
- строки выводятся в правильном порядке.

<details>
  <summary>Подсказка 1</summary>

Для создания модуля выполните `go mod init example.com/hello-go` внутри новой папки.
</details>

<details>
  <summary>Подсказка 2</summary>

Для вывода строки понадобится пакет `fmt` и функция `fmt.Println`.
</details>

<details>
  <summary>Решение</summary>

```go
package main

import "fmt"

func main() {
	fmt.Println("Привет, Go!")
	fmt.Println("Я учусь писать backend на Go.")
}
```

Запустите:

```bash
go run .
```
</details>

## Задание 2. Представьтесь

Измените программу так, чтобы она выводила ваше имя и город. Например:

```text
Меня зовут Анна.
Я пишу код из Казани.
```

Не копируйте решение из предыдущего задания полностью: измените строки самостоятельно.

**Критерии проверки:**

- программа по-прежнему запускается через `go run .`;
- в выводе есть ваше имя и город;
- каждая фраза печатается с новой строки.

<details>
  <summary>Подсказка</summary>

`fmt.Println` можно вызвать несколько раз внутри одной функции `main`.
</details>

<details>
  <summary>Возможное решение</summary>

```go
package main

import "fmt"

func main() {
	fmt.Println("Меня зовут Анна.")
	fmt.Println("Я пишу код из Казани.")
}
```

Замените имя и город на свои.
</details>

## Задание 3. Соберите программу

Соберите текущий проект командой `go build .`, затем запустите получившийся файл. После проверки удалите файл сборки вручную.

**Критерии проверки:**

- `go build .` завершается без ошибок;
- в папке появляется `hello-go` или `hello-go.exe`;
- запуск файла выводит тот же текст, что и `go run .`.

<details>
  <summary>Подсказка</summary>

В macOS/Linux файл запускается как `./hello-go`. В PowerShell используйте `.\hello-go.exe`.
</details>

<details>
  <summary>Почему вывод совпадает?</summary>

`go run .` временно собирает и запускает программу. `go build .` сохраняет результат сборки в исполняемый файл, который можно запустить отдельно.
</details>

## Мини-задача для будущего Task Manager API

Создайте отдельную папку `task-manager` и инициализируйте в ней модуль `example.com/task-manager`. Код писать пока не нужно: это будет основой сквозного проекта.

**Критерий проверки:** в папке `task-manager` есть файл `go.mod` с первой строкой:

```text
module example.com/task-manager
```
