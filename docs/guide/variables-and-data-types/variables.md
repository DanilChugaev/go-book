# Переменные и константы

## Цель урока

Научиться хранить данные в переменных, выбирать между `var` и `:=`, понимать нулевые значения и создавать понятные константы.

## Что такое переменная

Переменная — это имя, по которому программа обращается к значению. Например, в переменной можно хранить название задачи, её приоритет или число выполненных действий.

У каждой переменной есть тип. Он определяет, какие значения допустимы и какие операции с ними возможны. В Go тип можно указать явно или поручить компилятору определить его по значению.

```go
package main

import "fmt"

func main() {
	var taskTitle string = "Изучить Go"
	priority := 2

	fmt.Println(taskTitle, priority)
}
```

## Объявление через `var`

Полная форма объявления выглядит так:

```go
var name type = value
```

Пример:

```go
var title string = "Купить продукты"
var priority int = 1
var completed bool = false
```

Если тип очевиден из значения, его можно не писать:

```go
var title = "Купить продукты" // string
var priority = 1               // int
```

`var` используют, когда нужен явный тип, нужно объявить значение без начального значения или переменная объявляется за пределами функции.

## Короткое объявление `:=`

Внутри функции чаще используют короткую форму:

```go
title := "Купить продукты"
priority := 1
completed := false
```

Компилятор сам выводит тип из правой части. Короткое объявление работает **только внутри функции**.

```go
package main

import "fmt"

func main() {
	title := "Подготовить отчёт"
	title = "Подготовить недельный отчёт"

	fmt.Println(title)
}
```

После объявления значение переменной можно менять, но новый тип присвоить нельзя:

```go
priority := 1
priority = 2      // допустимо
// priority = "high" // ошибка: string нельзя присвоить int
```

::: warning Не путайте `:=` и `=`
`:=` создаёт хотя бы одну новую переменную. `=` присваивает новое значение уже существующей переменной.
:::

## Нулевые значения

Если объявить переменную через `var`, но не присвоить значение, Go даст ей нулевое значение соответствующего типа.

```go
package main

import "fmt"

func main() {
	var priority int
	var completed bool
	var description string

	fmt.Printf("priority=%d, completed=%t, description=%q\n", priority, completed, description)
}
```

Вывод:

```text
priority=0, completed=false, description=""
```

| Тип | Нулевое значение |
| --- | --- |
| Целые и дробные числа | `0` |
| `bool` | `false` |
| `string` | `""` |

Нулевое значение — нормальная часть языка, а не «мусор» в памяти. Позднее появятся нулевые значения для более сложных типов.

## Константы

Константа — значение, которое нельзя изменить после объявления. Константы объявляют ключевым словом `const`:

```go
const maxTitleLength = 120
const defaultPriority = 2
```

Константы подходят для правил и значений, которые не должны меняться во время работы программы. Например, для допустимой длины заголовка или кодов приоритета.

```go
package main

import "fmt"

const defaultPriority = 2

func main() {
	priority := defaultPriority
	fmt.Println(priority)
}
```

Попытка изменить константу — ошибка компиляции:

```go
const maxTitleLength = 120
// maxTitleLength = 200 // нельзя изменить константу
```

## Последовательные константы и `iota`

Внутри блока `const` идентификатор `iota` начинается с `0` и увеличивается на единицу в каждой следующей строке. Это удобно для фиксированных наборов значений.

```go
const (
	priorityLow = iota + 1
	priorityMedium
	priorityHigh
)
```

Значения будут такими:

```text
priorityLow    = 1
priorityMedium = 2
priorityHigh   = 3
```

В будущих уроках мы применим такой подход для статусов и приоритетов задач. Пока важно помнить: `iota` работает только в блоке `const`, а первая строка здесь начинается с `iota + 1`, поэтому отсчёт идёт с единицы.

## Имена и область видимости

Имена должны объяснять назначение значения:

```go
taskTitle := "Оплатить интернет"
maxTitleLength := 120
isCompleted := false
```

В Go используют `camelCase`. Имя с заглавной буквы экспортируется из пакета и становится доступно коду из других пакетов; эту тему разберём вместе с пакетами. Внутри одной функции сейчас используйте строчные имена, если нет специальной причины делать иначе.

Переменная существует в области, где объявлена. В этом уроке все переменные находятся внутри `main`, поэтому доступны только внутри её фигурных скобок.

## Частые ошибки

### Неиспользуемая переменная

Локальную переменную нельзя объявить и забыть использовать:

```go
func main() {
	title := "Изучить Go"
	// ошибка: declared and not used: title
}
```

Добавьте использование, например `fmt.Println(title)`, либо удалите переменную.

### `:=` вне функции

Такой код не скомпилируется:

```go
// title := "Изучить Go"
```

За пределами функции используется `var` или `const`.

### Повторное `:=` без новой переменной

```go
title := "Первая задача"
// title := "Вторая задача" // ошибка: no new variables on left side of :=
title = "Вторая задача"
```
