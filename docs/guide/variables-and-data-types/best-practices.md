# Лучшие практики: переменные и базовые типы

- Внутри функций по умолчанию используйте `:=`, если тип очевиден из значения; `var` оставляйте для нулевого значения и явного типа.
- Объявляйте переменную как можно ближе к месту первого использования.
- Давайте значениям имена по смыслу: `taskTitle`, `priority`, `completed`, а не `x`, `data` или `value` без контекста.
- Используйте `const` для неизменяемых правил и значений, а не для данных, которые меняются во время работы программы.
- Начинайте с `int`, пока формат данных или внешний API не требуют конкретный размер, например `int64`.
- Проверяйте диапазон до преобразования к более узкому числовому типу: преобразование само по себе не валидирует данные.

## Чек-лист

В коде нет неиспользуемых переменных, `:=` не применяется за пределами функции, а каждая константа описывает устойчивое правило, а не временное состояние.
