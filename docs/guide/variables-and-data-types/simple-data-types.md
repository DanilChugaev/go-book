# Простые типы данных

Go делит типы на простые и составные. Начнём с простых.

## Числовые типы

| Тип                    | Размер                             | Диапазон                              | Когда использовать                    |
|------------------------|------------------------------------|---------------------------------------|---------------------------------------|
| int                    | 32 или 64 бит (зависит от системы) | платформенно-зависимый                | Обычные целые числа                   |
| int8                   | 8 бит                              | -128..127                             | Когда точно знаешь маленький диапазон |
| int16                  | 16 бит                             | -32768..32767                         |                                       |
| int32                  | 32 бит                             | -2.1 млрд..2.1 млрд                   |                                       |
| int64                  | 64 бит                             | ±9 квинтиллионов                      | Большие числа                         |
| uint*                  | Беззнаковые версии (0 и выше)      |                                       |                                       |
| byte                   | uint8                              | 0..255                                | Байты, ASCII                          |
| rune                   | int32                              | -2.1 млрд..2.1 млрд, но для Unicode   | Один символ Unicode                   |
| float32                | 32 бит                             | ~±3.4e38, точность ~7 знаков          | Когда нужна экономия памяти           |
| float64                | 64 бит                             | ~±1.8e308, точность ~15 знаков        | По умолчанию для дробных              |
| complex64 / complex128 | Комплексные числа                  |                                       |                                       |
  
**Пример:**

```go
var (
    temperature int8 = -5
    population  uint = 8000000000
    pi          float64 = 3.1415926535
    imaginary   complex128 = 1 + 2i
)
```

## bool

Только `true` и `false`. Нельзя привести число к bool (в отличие от C).

## string

- Неизменяемая (immutable) последовательность байтов в кодировке UTF-8.
- Можно конкатенировать: `s := "Hello" + " " + name`.
- Длина: `len(s)` — количество байтов, а не символов!
- Доступ по индексу: `s[0]` — байт (uint8), а не rune.

**Очень важный пример (типичная ошибка новичков):**

```go
s := "Привет"           // 6 русских букв
fmt.Println(len(s))     // 12! Потому что каждый русский символ — 2 байта в UTF-8
fmt.Println(s[0])       // 208 (байт), а не символ 'П'
```

Чтобы работать с символами (рунами):

```go
for i, runeValue := range s {
    fmt.Printf("Индекс %d: символ %c (код %U)\n", i, runeValue, runeValue)
}
// range автоматически декодирует UTF-8 в rune
```

## Преобразование типов (Type Conversion)

В Go нет неявных преобразований (implicit conversion). Нужно явно писать `тип(значение)`.

**Примеры:**

```go
var i int = 42
var f float64 = float64(i)  // int → float64
var u uint = uint(f)

a := 3.99
b := int(a)  // 3 (отбрасывает дробную часть, НЕ округляет!)
```

**Полезные преобразования:**

```go
// string ↔ []byte
bytes := []byte("Hello")
str := string(bytes)

// string ↔ []rune (для работы с символами)
runes := []rune("Привет")  // [1055, 1088, 1080, 1074, 1077, 1090]
str2 := string(runes)
```

## Типичные ошибки новичков

1. `declared but not used` — объявив переменную, обязательно используй.
2. `len("Привет")` думают, что вернёт 6, а не 12.
3. Попытка изменить строку: `s[0] = 'А'` — нельзя, строки immutable.
4. Неявное преобразование: `var f float64 = 3.14; i := int(f + 1)` — работает, потому что 1 — untyped constant.
5. Смешивание signed/unsigned: `var i int = -1; var u uint = uint(i)` — даст огромное число.
