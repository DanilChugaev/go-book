# Map: ключ и значение

## Цель урока

Научиться хранить значения по уникальному ключу, создавать и изменять map, безопасно искать элементы, удалять их и обходить все пары.

В Task Manager API map позволит обращаться к названию задачи по её ID. Например, по ключу `42` можно получить значение `"Купить молоко"`.

## Что такое map

`map` хранит пары **ключ → значение**. Ключ уникален: одному ключу соответствует одно текущее значение.

```go
taskTitles := map[int]string{
	1: "Купить молоко",
	2: "Оплатить интернет",
	3: "Прочитать книгу",
}
```

В этом примере:

- `int` — тип ключа, ID задачи;
- `string` — тип значения, название задачи;
- `1`, `2`, `3` — ключи;
- тексты задач — значения.

Общий вид типа:

```go
map[типКлюча]типЗначения
```

Map подходит для поиска по идентификатору, кода статуса, имени настройки или другого уникального признака. Если важен порядок элементов, чаще нужен слайс.

## Создание map

Map можно создать литералом:

```go
priorityLabels := map[int]string{
	1: "низкий",
	2: "средний",
	3: "высокий",
}
```

Пустую map создают через `make`:

```go
taskTitles := make(map[int]string)
```

После этого в неё можно записывать значения:

```go
taskTitles[1] = "Купить молоко"
taskTitles[2] = "Оплатить интернет"
```

Можно указать примерное число элементов — это необязательная подсказка для рантайма:

```go
taskTitles := make(map[int]string, 10)
```

## Чтение по ключу

Чтобы получить значение, укажите ключ в квадратных скобках:

```go
taskTitles := map[int]string{
	1: "Купить молоко",
}

title := taskTitles[1]
fmt.Println(title) // Купить молоко
```

Если ключа нет, map вернёт нулевое значение типа значения:

```go
title := taskTitles[999]
fmt.Printf("%q\n", title) // ""
```

Это не всегда достаточно для проверки: пустая строка может быть и настоящим значением. Поэтому при поиске обычно используют форму `value, ok`.

## Проверка наличия ключа: `value, ok`

Во второй переменной Go возвращает `true`, если ключ существует, и `false`, если его нет:

```go
taskTitles := map[int]string{
	1: "Купить молоко",
}

title, exists := taskTitles[1]
fmt.Println(title, exists) // Купить молоко true

title, exists = taskTitles[999]
fmt.Println(title, exists) //  false
```

Так можно безопасно найти задачу по ID:

```go
taskID := 2

if title, exists := taskTitles[taskID]; exists {
	fmt.Println("Найдена задача:", title)
} else {
	fmt.Println("Задача не найдена")
}
```

Если само значение не нужно, используйте `_`:

```go
if _, exists := taskTitles[taskID]; exists {
	fmt.Println("ID уже занят")
}
```

## Добавление и обновление

Запись по новому ключу добавляет пару. Запись по существующему ключу заменяет значение:

```go
taskTitles := make(map[int]string)

taskTitles[1] = "Купить молоко" // добавление
taskTitles[1] = "Купить продукты" // обновление

fmt.Println(taskTitles[1]) // Купить продукты
```

Map не хранит историю изменений ключа: после обновления старое значение недоступно, если вы не сохранили его отдельно.

## Удаление

Для удаления пары используйте встроенную функцию `delete`:

```go
taskTitles := map[int]string{
	1: "Купить молоко",
	2: "Оплатить интернет",
}

delete(taskTitles, 1)

fmt.Println(taskTitles) // map[2:Оплатить интернет]
```

Удаление отсутствующего ключа безопасно: ничего не произойдёт.

```go
delete(taskTitles, 999)
```

`delete` не возвращает результат. Если важно сообщить пользователю, была ли задача удалена, сначала проверьте наличие ключа через `value, ok`.

## Длина map

`len` возвращает число пар:

```go
taskTitles := map[int]string{
	1: "Купить молоко",
	2: "Оплатить интернет",
}

fmt.Println(len(taskTitles)) // 2
```

После добавления длина увеличится, после удаления — уменьшится.

## Обход через `range`

`range` для map возвращает ключ и значение:

```go
taskTitles := map[int]string{
	1: "Купить молоко",
	2: "Оплатить интернет",
}

for id, title := range taskTitles {
	fmt.Printf("%d. %s\n", id, title)
}
```

::: warning Порядок map не определён
Не рассчитывайте на порядок обхода map. Один запуск может вывести сначала ID `1`, затем `2`, а другой — в обратном порядке. Если пользователю нужен отсортированный список, позже мы соберём ключи в слайс и отсортируем его.
:::

Если нужен только ключ или только значение:

```go
for id := range taskTitles {
	fmt.Println(id)
}

for _, title := range taskTitles {
	fmt.Println(title)
}
```

## Ключи map

Ключ должен быть значением, которое можно сравнить через `==`. Для начала используйте простые типы:

- `int` для ID;
- `string` для имён, кодов и настроек;
- `bool` в редких случаях.

Слайс нельзя использовать ключом:

```go
// invalid := map[[]string]int{} // ошибка компиляции
```

Причину и более сложные правила сравнения типов разберём позднее. Пока выбирайте для ключа ID или строковый код.

## Полная работа с задачей по ID

```go
package main

import "fmt"

func main() {
	taskTitles := map[int]string{
		1: "Купить молоко",
		2: "Оплатить интернет",
	}

	taskTitles[3] = "Прочитать книгу"
	taskTitles[2] = "Оплатить коммунальные услуги"

	taskID := 2
	if title, exists := taskTitles[taskID]; exists {
		fmt.Printf("Задача %d: %s\n", taskID, title)
	} else {
		fmt.Println("Задача не найдена")
	}

	delete(taskTitles, 1)

	fmt.Println("Всего задач:", len(taskTitles))
}
```

## Частые ошибки

### Попытка определить отсутствие ключа через нулевое значение

```go
title := taskTitles[42]

if title == "" {
	// Неясно: ключа нет или в map хранится пустая строка?
}
```

Используйте `title, exists := taskTitles[42]`.

### Ожидание определённого порядка

```go
for id, title := range taskTitles {
	fmt.Println(id, title)
}
```

Не используйте такой обход, если первая выведенная задача должна быть «самой ранней» или «с наименьшим ID».

### Запись в nil map

```go
var taskTitles map[int]string
// taskTitles[1] = "Купить молоко" // panic: assignment to entry in nil map
```

Создайте map через `make` или литерал до записи:

```go
taskTitles := make(map[int]string)
taskTitles[1] = "Купить молоко"
```
