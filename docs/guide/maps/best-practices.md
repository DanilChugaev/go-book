# Лучшие практики: map

- Используйте map для поиска по уникальному ключу, а не для упорядоченного списка.
- Проверяйте наличие ключа через `value, ok`, если нулевое значение может быть настоящими данными.
- Инициализируйте map через литерал или `make` до первой записи.
- Не полагайтесь на порядок `range` по map; сортируйте ключи отдельно, если порядок нужен пользователю.
- Удаление отсутствующего ключа безопасно, но при необходимости сообщить результат сначала проверьте `ok`.
- Не изменяйте map одновременно из нескольких goroutine без синхронизации.

## Чек-лист

Ключ соответствует смыслу данных, чтение отсутствующей записи обработано, а API не обещает порядок элементов там, где map его не гарантирует.
