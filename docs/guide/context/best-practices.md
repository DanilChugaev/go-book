# Лучшие практики: context

- Передавайте `context.Context` первым параметром функции, которая выполняет отменяемую работу.
- Создавайте дочерний context от полученного родителя, а не от нового `Background` внутри операции.
- Всегда сохраняйте и вызывайте `cancel`, обычно через `defer cancel()`.
- Проверяйте `ctx.Done()` в блокирующих `select` и `ctx.Err()` между шагами долгой работы.
- Возвращайте `ctx.Err()` как причину отмены или истечения дедлайна.
- Не храните context в структуре и не используйте его вместо обычных параметров.

## Чек-лист

Отмена проходит по всей цепочке вызовов, goroutine умеют завершаться по `Done`, а дедлайн не маскирует утечку работы, которая не слушает context.
