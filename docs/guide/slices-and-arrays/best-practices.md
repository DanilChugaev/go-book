# Рекомендации по коду: массивы и слайсы

- В прикладном коде по умолчанию выбирайте слайс; массив используйте, только если фиксированный размер — часть модели.
- Всегда сохраняйте результат `append`: `items = append(items, value)`.
- Проверяйте индекс до доступа, удаления или среза, если он приходит из переменной или внешнего ввода.
- Создавайте `make([]T, 0, capacity)`, когда планируете добавлять элементы через `append`.
- Для независимой копии используйте `copy`, а не обычное присваивание слайса.
- Не удерживайте маленьким слайсом большой исходный массив без причины; при долгом хранении делайте копию нужной части.

## Чек-лист

Код учитывает пустой слайс, результат `append` не теряется, а изменение копии не должно неожиданно менять исходные данные.
