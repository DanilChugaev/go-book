# Практика: список названий задач

Теперь Task Manager API умеет хранить несколько названий задач в слайсе. Мы пока работаем только со строками; полноценная задача со свойствами появится после изучения структур.

## Задание 1. Выведите список

Создайте слайс из трёх названий задач и выведите их с нумерацией начиная с единицы:

```text
1. Купить молоко
2. Оплатить интернет
3. Прочитать книгу
```

Используйте `range`.

**Критерии проверки:**

- используется литерал `[]string`;
- в `range` получаются индекс и название;
- к индексу прибавляется `1`;
- каждая задача выводится с новой строки.

<details>
  <summary>Подсказка</summary>

Форматированный вывод:

```go
fmt.Printf("%d. %s\n", index+1, title)
```
</details>

<details>
  <summary>Решение</summary>

```go
package main

import "fmt"

func main() {
	titles := []string{
		"Купить молоко",
		"Оплатить интернет",
		"Прочитать книгу",
	}

	for index, title := range titles {
		fmt.Printf("%d. %s\n", index+1, title)
	}
}
```
</details>

## Задание 2. Добавьте задачу

Создайте пустой слайс названий с вместимостью `3`, затем добавьте в него три задачи через `append`. После каждого добавления не выводите промежуточный результат: выведите готовый список через `range`.

**Критерии проверки:**

- слайс создан через `make([]string, 0, 3)`;
- каждый вызов `append` присваивается обратно переменной;
- в готовом списке три названия;
- порядок добавления сохранён.

<details>
  <summary>Подсказка</summary>

```go
titles = append(titles, "Купить молоко")
```
</details>

<details>
  <summary>Решение</summary>

```go
package main

import "fmt"

func main() {
	titles := make([]string, 0, 3)

	titles = append(titles, "Купить молоко")
	titles = append(titles, "Оплатить интернет")
	titles = append(titles, "Прочитать книгу")

	for index, title := range titles {
		fmt.Printf("%d. %s\n", index+1, title)
	}
}
```
</details>

## Задание 3. Удалите задачу по индексу

В списке из трёх задач удалите задачу с индексом `1` — вторую по счёту. Перед удалением проверьте, что индекс допустим. Выведите обновлённый список.

**Критерии проверки:**

- проверяется условие `index >= 0 && index < len(titles)`;
- используется `append(titles[:index], titles[index+1:]...)`;
- в результате остаются первая и третья задачи;
- программа не паникует при недопустимом индексе.

<details>
  <summary>Подсказка</summary>

Слайс до элемента: `titles[:index]`. Слайс после элемента: `titles[index+1:]`.
</details>

<details>
  <summary>Решение</summary>

```go
package main

import "fmt"

func main() {
	titles := []string{
		"Купить молоко",
		"Оплатить интернет",
		"Прочитать книгу",
	}
	index := 1

	if index >= 0 && index < len(titles) {
		titles = append(titles[:index], titles[index+1:]...)
	}

	for itemIndex, title := range titles {
		fmt.Printf("%d. %s\n", itemIndex+1, title)
	}
}
```
</details>

## Задание 4. Сделайте резервную копию

Создайте список из двух задач и его независимую резервную копию. Измените первый элемент резервной копии на `Отменённая задача`, затем выведите оба списка.

**Критерии проверки:**

- резервная копия создана через `make` и `copy`;
- изменение резервной копии не меняет исходный слайс;
- первый элемент исходного списка остаётся прежним;
- первый элемент копии меняется.

<details>
  <summary>Подсказка</summary>

Создайте `backup := make([]string, len(titles))`, затем вызовите `copy(backup, titles)`.
</details>

<details>
  <summary>Решение</summary>

```go
package main

import "fmt"

func main() {
	titles := []string{"Купить молоко", "Оплатить интернет"}
	backup := make([]string, len(titles))

	copy(backup, titles)
	backup[0] = "Отменённая задача"

	fmt.Println("Исходный список:", titles)
	fmt.Println("Резервная копия:", backup)
}
```
</details>

## Проверьте себя

Перед следующей главой убедитесь, что вы можете:

- объяснить разницу массива и слайса;
- добавить элемент через `append` без потери результата;
- проверить индекс до доступа к элементу;
- получить часть слайса выражением `from:to`;
- удалить элемент по индексу;
- создать независимую копию через `copy`.
