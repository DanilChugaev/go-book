# Рекомендации по коду: файлы и ввод-вывод

- Для небольшого файла используйте `os.ReadFile` и `os.WriteFile`; не усложняйте код без необходимости.
- После успешного `os.Open` или `os.Create` сразу добавляйте `defer file.Close()`.
- Оборачивайте ошибки файловой системы контекстом: путь и операция важны для диагностики.
- Различайте отсутствие ожидаемого файла через `errors.Is(err, os.ErrNotExist)`.
- Не держите файл открытым дольше необходимого.
- Не используйте `os.ReadFile` для большого или бесконечного потока данных.

## Чек-лист

Каждый открытый файл закрывается, путь задаётся явно, ошибки чтения и записи не игнорируются, а формат экспорта отделён от файловой операции.
